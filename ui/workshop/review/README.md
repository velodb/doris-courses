## 当前保留的边界

- 托管登录预览只表达品牌样式意图，三版共用保守的居中布局；不承诺可以改变真实表单结构、字体、帮助链接或平台文案。已删除预览中原本可能误导为可插入的自有帮助链接。账号帮助在自有页面提供。认证版本及最终 CSS 需实施前实查。
- 课程目录为真实十模块。Module 1 有真实内容片段、SQL 和源课程插图；其余阅读入口标明为布局占位，不伪造其他模块内容。
- JupyterLab / Doris 原生页面未重新设计。原型停在明确的外部打开边界，后续真实链接从已验证 assignment / 课程 manifest 产生。
- 身份、活动与可用状态为明确标注的示例。没有健康查询、资源操作、进度、成绩、结课证书或持久存储。
- 退出文案仅承诺当前入口退出，并提示关闭其他服务标签；不承诺全站即时注销。
