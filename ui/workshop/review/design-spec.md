状态：三方向共同输入保留；用户随后已选A，当前深化稿待整套设计评审。用户本轮指令：「根据 @plan-doc/aws，开始下一步 AWS-27.1。页面设计使用 $huashu-design」。方向选择见 direction-approved.md，当前UI位于独立 ui/workshop/。

## 目标与场景

这是 Apache Doris 课程在 AWS workshop 环境中的学习入口。它面向参加现场或远程实操活动的学员，主要使用笔记本浏览器，偶尔用手机查看登录与活动信息。平台已经有活动列表、活动独立认证、账号固定绑定个人环境、课程 Markdown、Notebook 和 Doris FE 等功能。本次设计要把这些已经存在的能力组织成清楚的学习路径，让第一次使用的学员知道从哪里开始，让切换工具的学员能够辨认自己仍在同一活动中。它不是课程销售网站，也不是管理云资源的运维控制台。

主要问题是不同页面之间缺少连续的导航与身份提示。公共入口需要解释选择活动后将使用组织者提供的账号登录；个人首页需要同时回答「我是谁」「当前活动是什么」「课程从哪里开始」「配套网页在哪里」；阅读页要把课程正文放在中心，同时给出对应 Lab 和返回课程入口。视觉母题取自课程的实际工作方式：阅读、运行实验、观察结果。三个方向都应让这条路径成为版式结构，而不是添加抽象数据库插画。

## 真实内容及页面范围

- 活动列表：仅使用已配置且未过期的活动。初稿只有一个明确标注为示例的 `demo-rta` 活动，不复用已退役活动的 URL、日期或口令。
- 登录衔接：活动选择后离开自有入口，进入该活动的 Cognito 托管页。登录界面保持居中、纵向表单，只探索 logo、文字和有限颜色样式，不画任意可定制的左右布局。
- 首次改密、登录错误、MFA 衔接：表单的字段、提示和真实挑战均由 Cognito 决定。初稿只表现设计意图，不收集密码、不发出认证请求。
- 个人首页：示例学员 `s001`；仅本人已分配的五类源服务（`jupyter`、`doris`、`fe1`、`fe2`、`fe3`）。课程、Notebook 和终端是同一 Jupyter origin 的不同目的地，不发明第六个独立服务。Web Terminal 保持通过 JupyterLab 菜单启动的引导。
- 课程首页：rta-main 的十个现有模块，标题和顺序来自 `doris-course/01-real-time-analytics/course.yaml`。不把选修或其他课程纳入本轮支持范围。
- 阅读页：Module 1 的真实目标、标题、SQL 和配图来自仓库正文。长文为内容片段预览，完整渲染留到所选方向深化阶段。
- 状态：无活动、活动结束、环境未就绪、未分配权限、会话到期、登录失败、退出当前入口、密码帮助。

## 语言、品牌与素材假设

用户已明确确认「沿用英文与 Apache Doris 品牌」，与现有课程清单及运行页面一致。采用 Apache Doris 官方主标识和深底版本，Jupyter 标识只在相关服务旁使用。颜色从官方标识的绿与墨色推导，中性色可因方向改变明度和色温；不把方向色板写成 Apache 官方 VI。没有宣传摄影需求。工具页面不使用装饰性 stock 图；阅读内容引用仓库真实配图。字体使用本地取得并内嵌的 Manrope 与 Newsreader，附带许可证。

## 输出规格

三版均为独立纯 HTML/CSS/JavaScript 文件，字体、logo、课程配图全部 data URL 内嵌，复制单文件后双击可用，无外部 CDN、无后端和云端连接。共同桌面比较尺寸为 1440×1000 px；另以 390×844 和 768×1024 检查布局。正文至少 14px，辅助标签至少 12px，正文及按钮文字对比度至少 4.5:1。顶部预览工具条属于设计评审外壳，可切换页面与异常状态，不是最终产品的一部分。初稿的示例身份、登录、状态和跳转不能被解释为真实环境健康或认证结果。

## 三个独立思考锚点

A：秒数轮盘记录 49，49 % 20 + 1 = 10，对应网页半区 Bauhaus Geometric。把教学步骤组织成明确的编号板块和鲜明的品牌色区域，避免为几何而画装饰图形。

B：现实参照 IBM Carbon 的任务导向产品界面。迁移密度、栅格和持久侧栏的组织方式，品牌仍属于 Doris，不复制 IBM 标识，不暗示合作。

C：以 Information Architects 对聚焦阅读的取舍为思考锚点，自行提出课程入口。重点是长文阅读与实验动作，采用出版物式层级、横向主导航、首课阅读区和下方工具横栏，不暗示对方参与本项目。

三版的导航位置、主构图和服务组织至少一项结构性不同，不使用同一布局只换颜色。共用相同内容、真实素材及状态语义，便于横向比较。
