# A「实验手册」设计规范

用户选择：「选A」。语言与品牌：「沿用英文与 Apache Doris 品牌」。本规范是该方向的深化交付，完整设计仍待用户评审；不是运行页面已接入的声明。

可打开 [完整原型](../../dist/prototype.html) 和 [组件参考页](../../dist/components.html)。UI 源码、资源、文案与构建脚本均位于独立的 `ui/workshop/`；课程内容和管控逻辑仍由各自目录维护。

## 构图与层级

页面从真实学习动作推导：先阅读，再运行实验，最后观察结果。个人首页的绿色课程主区承担首个动作，右侧按行列出辅助工具，编号表达操作板块而不是进度。保留 A 初稿的方正网格、横向规则线和课程主区右上角的大切圆；其他组件仅用 4px 小圆角，不把每个区块都包成卡片。

首屏优先级依次为当前页面任务、课程入口、本人归属、实验工具。账号归属为「Assigned to s001」，不使用「Healthy」「Running」等尚无数据源的服务健康声明。大号编号无进度含义，装饰编号从无障碍树隐藏。

## 排印

页面使用内嵌 Manrope，保留许可；代码使用本机等宽字体。常规正文16px，阅读17px/1.85行高，模块摘要和工具说明14px；12–13px仅用于辅助标签、编号元信息、页脚和目录。内联代码最小14px。

桌面主标题48px、阅读标题44px；手机主标题36px、阅读35px；320px时主标题32px。服务标题18px、模块标题17px。大标题收紧字距；英文眉题12px且适度加字距。正文使用 `text-wrap: pretty`，不靠硬编码换行处理长模块名；活动 hero 的两处手动换行服务于已选版式。

托管认证页保留平台式系统字体示意，不能把自有页面字体规范直接等同于 Cognito 支持上传字体。

## 组件

| 组件 | 规则与行为 |
| --- | --- |
| 品牌栏 | 左侧官方 Doris 标识；本人页面右侧显示活动和学员，只提供当前入口退出 |
| 顶部导航 | 自有页面共享 My workspace / Course outline / Web Terminal，当前项同时加字重与底线 |
| 面包屑 | 使用真实导航链接和当前页文字；不把 `learner_id` 当可切换资源入口 |
| 主操作 | 墨色底、白字、至少48px高；每个任务区一个主操作 |
| 次操作 | 透明底、可辨边界；不与主操作同等抢眼 |
| 文字链接 | 默认下划线，至少44px的主要交互高度；普通长文内联链接不扩成按钮 |
| 方向标识 | 同页面路由用 →；真实外部服务入口用 ↗，同时提供「Open separately」文字说明 |
| 课程主区 | 绿色背景，墨色文字，右上64px切圆；序号01仅表达板块 |
| 工具行 | 大编号、工具标题和方向标识；整行可操作，默认不展示解释段落 |
| 分组课程列表 | 来自 manifest 的 level 和顺序；模块标题 + Read lesson / Open Lab，无摘要和完成状态 |
| 阅读区 | 真正源课程 Markdown；表格与代码在自身容器滚动，正文不横向溢出 |
| 阅读工具侧栏 | 桌面 sticky；手机位于正文前，当前 Lab 按钮始终明确，目录默认折叠 |
| 提示 | 分隔线加简短文字，一句话提示活动结束或替换前下载文件 |
| 异常页 | 状态眉题、标题、原因范围、恢复步骤、主操作与账号帮助 |
| 托管页预览 | logo + 居中纵向表单；只读字段，不植入自有导航或帮助链接 |

组件参考页中的样式来自同一 `src/styles.css`，不维护另一套 CSS。

## 响应式

| 宽度 | 行为 |
| --- | --- |
| >1100px | 课程主区与工具区两列；课程列表标题/操作同行；阅读正文 + 工具侧栏 |
| 701–1100px | 减少间距和字号；课程操作可换行；两列阅读仍保留 |
| ≤700px | 个人首页单列，工具自然下移；导航保持可见、可横向滚动；身份栏隐藏活动长 ID，保留学员和退出 |
| ≤359px | 左右16px，进一步收紧主标题；活动主操作跨整行，避免320px屏幕被窄列挤压 |

不设置主页面固定高度。320、390、768、1440px均检查，长代码和表格滚动范围不扩大页面宽度。字号预览到20px后仍需在320px可阅读。

## 无障碍与交互

- 一个页面一个 h1；标题层级取自内容，导航和侧栏有名称。
- 跳过导航链接可键盘操作；页内目录移动焦点到真实标题，采用 `window.scrollTo`，不用 `scrollIntoView`。
- 页面切换移动焦点到标题，并更新英文文档标题和状态播报；浏览器前进/后退可用。
- 主要链接及按钮可键盘操作，焦点环3px墨色，不以颜色作为唯一提示。
- 图片保留源课程替代文字；只用于排版的编号/箭头从无障碍树隐藏。
- 表格/代码滚动区可聚焦，并提供区域名称。
- 文本对比度按正文4.5:1、大号标题3:1检查；此项不等于完整 WCAG 认证。
- 降低运动偏好下不启用过渡。主页面没有持续动画。
- localStorage仅用于评审的视觉偏好，不写身份、会话、模块、路由、进度或成绩。

## 已保留与未覆盖

保留实际账号与服务归属、原有服务 origin、临时文件和入口退出的真实边界。JupyterLab、Doris原生界面不做深度重绘；托管页的字段、文案和挑战顺序以平台实际返回为准。设计原型并不执行认证、开机、重建、销毁或健康探测。


## 文案精简修订

用户要求：「页面的文字内容太多了，尽量精简掉一些说明性文字。」沿用A方向，只精简UI外壳。

- 标题直接说明页面用途；移除入口宣传标题、准备介绍和首页学习流程说明。
- 工具只保留名称和打开方式；本人归属不再另设说明面板。
- 目录只列模块标题与阅读/Lab动作；正文和课程内配图、SQL、表格完整保留。
- 终端默认只呈现两步，已有终端说明折叠显示。
- 异常页保留状态、下一步及必要后果；没有补充信息时不渲染空白说明块。
- 保留退出范围、密码要求、会话到期后核对结果、下载文件提醒等会影响操作的信息。

主内容按可见英文词元统计：入口102→25、本人首页169→71、课程目录307→175、终端87→32；说明折叠后不计入默认可见文案。详见 [copy-reduction.json](copy-reduction.json)。
