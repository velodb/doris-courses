## 方向比较

A 的视觉锚点是绿色课程主板和工具编号：课程起点醒目，适合第一次进入的教学演示；同屏内容比 B 更舒展，需要接受适当滚动。

B 的视觉锚点是持久侧栏与较紧凑的任务区：重复切换工具时位置稳定；长文进入单独阅读区，窄屏侧栏变为水平导航。没有计费、监控仪表盘或管理资源动作。

C 的视觉锚点是衬线标题、纸色背景和单栏阅读主线：个人首页直接突出首课，工具在下方横栏；阅读页保留当前 Lab 动作，窄屏转换为纵向。阅读正文使用更大字号，页面更长。

三版均保留读取、运行实验和观察结果的工作方式；没有以「完成百分比」组织内容。三版托管页故意采用共同边界内的品牌方案，而不是为了差异化去发明三个认证布局。

## 实施约束与待定项

1. 当前自有门户 CSP 为 `default-src 'none'`，不能直接粘贴初稿内联 CSS/JS。所选方向应优先服务端渲染和同源静态样式；若必须变更 CSP，需精确声明所需资源策略并验证原负向测试。初稿脚本仅用于页面演示。
2. 当前 registry 未提供活动人类名称、起始时间、讲师联系方式或实时健康。实现应使用已存在 event/expiry 与已验证 assignment，额外数据先明确来源，不为了复刻设计编造信息或新增数据库。
3. 课程与个人服务横跨 origin。跨服务返回入口可以使用已验证配置生成的链接，不能相信任意 return URL。外部打开的最终实现使用 `noopener`，保留现有隔离和 websocket 边界。
4. 官网 SVG 的 viewBox 带有很大空白。初稿保留原始素材并派生仅收紧 viewBox 的版本，路径和颜色不变；不复用 SVG 样式注入生产文档。托管页未来单独转换 PNG，并验证文件大小。
5. 用户已明确确认「沿用英文与 Apache Doris 品牌」。本轮沿用英文，不引入中文/双语切换；不把评审工具条的中文说明当作产品本地化。
6. 具体 spacing/token/component 表及所有状态精修应在选择后围绕一套方向收敛，避免把三套规范都变成生产负担。
7. 账号帮助不提供自助注册或邮箱找回；admin_only 恢复保持。可在自有入口说明找组织者，真实托管页仅使用平台现有入口。

方向选定后的交付包括选定规范、完整状态文案、响应式规格、资源清单和运行源码实施范围。认证版本升级或原生工具深度改造需要单独说明后再确认，不能把视觉选择当作认证迁移授权。
