# Kazakh course files

The maintained sources are now in
[`doris-course/kk-Cyrl/`](../../doris-course/kk-Cyrl/README.md).
Edit those Markdown, Notebook, Quiz YAML, course manifest, image, code and data
files directly. The original course directory structure is preserved.

The former translation overlay, batches, source map and image/review JSON
registers were migrated once and removed from active authoring. Their history
remains in Git at `dfa31100d936cf1262648df44542a8a2e0c35dee`.
New builds use [course-file configuration](../course-files.yaml) and never
require changing an English source hash or an LLM review record.

The migration preserves the existing translations, original PNG pixels and
adjacent Kazakh label legends. It does not imply native human language review.
