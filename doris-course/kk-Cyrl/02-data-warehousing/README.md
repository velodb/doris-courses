# Apache Doris көмегімен деректер қоймасын құру

Бизнес сенетін тапсырыс қоймасын құрыңыз. Тапсырыстар мен тарихын пакетпен жүктеп, тек тексерілген кірісті сақтайсыз, әр өзгерісті қадағалап, факт/өлшемге модельдейсіз, жазылған келісімшартпен метрикаларға айналдырып, тақта/модельге жариялайсыз. Кейін рөл қатынауы, сыналған қайтаруы бар өмірлік цикл, әр жүктемеге жеке ресурспен басқарасыз. Әр жұмыс компьютеріңіздегі курс бастайтын Doris сынақ ортасында орындалып, өзіңіз тексере алатын сандармен салыстырады.

<a id="unit-u.c2f721226d694155b31e276c30ad75ef"></a>

<a id="who-this-course-is-for"></a>

## Курс кімдерге арналған

- Doris-те қойма құратын не құруға дайын дерек/аналитика инженерлеріне.
- `SELECT`, `WHERE`, `GROUP BY`, `JOIN` SQL жаза, `try` / `finally` бар шағын Python функциясын оқи, сөздік не шақыру мәнін өзгерте алуыңыз керек; 5-жұмыс HTTP жіберетіндіктен әдіс/URL/тақырып/күй кодын тану, `docker ps`, `docker logs` сияқты командаларды орындау қажет.
- Doris тәжірибесі керек емес. 1-модуль ортаны қосып, алғашқы кестеден өткізеді.

<a id="unit-u.688cbe73cef74b479013214620c82f3c"></a>

<a id="what-you-will-learn"></a>

## Не үйренесіз

- Doris деректі қалай жоспарлайды, сақтайды, жүктейді: FE/BE, tablet/rowset, үш кілт моделі, бөлімдер/бакеттер, Catalog арқылы деректер көлі кестелері, қайталағанда екі жүктемейтін пакеттер.
- Келген деректі дұрыс ұстау: бастапқы кірісті аралықта сақтау, қабылданбағанын себебімен бөлу, бизнес нұсқаларымен әр тапсырыстың ағымдағы күйі/тарихын ұстау, қатеден кейін қайта ойнату.
- Модельдеу/өлшеу: түйіршіктілігі жарияланған факт/өлшемдер, тапсырыс жоғалтпайтын/екі санамайтын біріктіру, жазылған келісімшартты метрикалар, егжей-тегжеймен салыстырылатын материалданған көріністер/қызмет кестелері.
- Тұтынушыға жариялау: тақта/модельге семантикалық көріністер, Doris кепілдігі мен BI/AI тексеруі арасындағы шекара.
- Қойманы пайдалану: рөл рұқсаттары мен дәлелі, сыналған қайтаруы бар сақтау бөлімдері, жүктемелер бірін-бірі баяулатпауына Workload Group және сұрау шектері.

## Орта

- **Қолдау көрсетілетін платформалар.** Әр жұмысы толық орындалған Apple Silicon macOS. x86-64 Linux сол бейнелерді қолданады, бірақ толық тексерілмеген. Windows-та WSL 2 қолданыңыз. Docker/Jupyter бір компьютерде: ноутбук контейнер бастап, `127.0.0.1` арқылы Doris-ке қосылады. Браузер басқа компьютерде бола алады.
- **Ресурстар.** Docker: 4 CPU, 8 GB жады, шамамен 20 GB бос диск. Қосымшаларға көбірек: 5A — 8 GiB, 5B — 10 GiB Docker жады, 4 CPU; екеуі сервистерімен қатар Doris-ті 6 GiB шекпен орындайды. 11-жұмыс тақтасына тағы 2 GiB, 13-жұмыс көшірмесіне 512 MiB шамасында.
- **Doris нұсқасы.** Apache Doris 4.1.3, `apache/doris:all-in-one-4.1.3` бейнесі, дайджесті `sha256:82a5cabc7900ebcd3d080412d636c0cebd6602799fffe2605c652b2ea7d42609`. `SHOW FRONTENDS`, `SHOW BACKENDS` `doris-4.1.3-rc02-7126cf65d96` көрсетеді: 4.1.3 — осы құрастырылым.
- **Жүктеулер.** Әр жұмыс алғаш қажет еткенде төменгі бейнелерді алады. Silo — MinIO серверінің ашық (AGPLv3) форкі, Pigsty қолдайды, MinIO S3 API-ымен; MinIO қауымдастық бейнелерін жариялауды тоқтатқандықтан курс соны қолданады.

## Бастау

1. Python 3.10–3.13 арқылы виртуалды орта құрып, тәуелділіктерін орнатыңыз. Тұтас репозиторийдің курс каталогында орындаңыз: ортақ ноутбук ортасы `../../common` ішінен орнатылады. `python3 --version` 3.14 көрсетсе, әлі қолдау жоқ, `python3.12` не `python3.13` қолданыңыз:

   ```bash
   cd doris-course/kk-Cyrl/02-data-warehousing
   python3.12 -m venv .venv
   .venv/bin/python -m pip install -r requirements.txt
   ```

   4–5 кеңейтіміне PyArrow да орнатыңыз: `.venv/bin/python -m pip install -e '.[extensions]'`.

2. Docker қосып, `docker info` сәтті болғанша күтіп, сол ортадан Jupyter бастаңыз. Бірнеше ядро болса `.venv` таңдаңыз.

   ```bash
   .venv/bin/jupyter lab
   ```

3. Markdown бастапқы мәтінмен ашылуы мүмкін: оң басып **Show Markdown Preview** таңдап, бетті/сілтемелерін оқыңыз. [1-модуль: Doris-пен танысу және алғашқы тапсырыстарды талдау](level1/module01-introduction/course.md) және `level1/module01-introduction/lab01_connect_and_query.ipynb` ашыңыз. **Initialize the Lab Tools** орындап, тазалау ескертуін оқып, **Start and Connect** орындаңыз. Алғаш бейне жүктеуі бірнеше минут алады; `connection_ok` 1 болғанда жалғастырыңыз. Кейінгілер сол ортаға қосылады.

## Тазалау

Кідірту үшін ортаны тоқтатып, дерегін сақтаңыз, кейін қайта бастаңыз:

```bash
docker compose --project-name doris-warehousing-course --file environments/single-node/compose.yml stop
docker compose --project-name doris-warehousing-course --file environments/single-node/compose.yml start --wait
```

Көл, ағын сервистері, тақта, көшірме сақтау солай тоқтайды: төмендегі жоба/файл командаларында `down --volumes` орнына `stop` қолданыңыз. 4-жұмыс көлді қайта қосады.

Бәрін жою үшін курс каталогында осы ретпен орындаңыз:

1. 5A/5B ағын сервистерін жойыңыз. Орта желісіне қосылғандықтан алдымен бұлар; тапсырмалары да аяқталады:

   ```bash
   docker compose --project-name doris-warehousing-streaming --file environments/streaming/compose.yml --profile kafka --profile cdc down --volumes
   ```

2. Ортаны база/пайдаланушы/рөл/топтарымен жойыңыз:

   ```bash
   docker compose --project-name doris-warehousing-course --file environments/single-node/compose.yml down --volumes
   ```

3. Көл/тақта/көшірме сақтауын жойыңыз. Олардың желісіне Doris қосылған, сондықтан ортадан кейін:

   ```bash
   docker compose --project-name doris-warehousing-lake --file environments/lakehouse/compose.yml down --volumes
   docker compose --project-name doris-warehousing-bi --file environments/bi/compose.yml down --volumes
   docker compose --project-name doris-warehousing-backup --file environments/backup/compose.yml down --volumes
   ```

4. Қаласаңыз құрастырылған `doris-course-superset:4.1.2-pydoris1.1.0`, `doris-course-flink:1.20.1-cdc3.4.0-doris25.0.0` және жүктелген бейнелерді `docker image rm` арқылы жойып, каталогтағы `.runtime/`, `.venv/` өшіріңіз.

Кейін `docker ps -a --filter name=doris-warehousing`, `docker volume ls --filter name=doris-warehousing` ештеңе көрсетпейді.
