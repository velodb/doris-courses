# Apache Doris көмегімен жүйені бақылау

Компьютерде онлайн дүкен іске қосып, ақау тудырыңыз және DOG стегімен тексеріңіз: OpenTelemetry Collector дүкеннің журналдары, метрикалары мен трассаларын жинайды; Apache Doris сақтап сұрайды; Grafana іздейді, диаграмма құрып ескертеді. Сегіз модульде бір инцидентті алғашқы сәтсіз тапсырыстан ақау біткенде шешілетін ескертуге дейін қадағалап, телеметрияға Doris кестелерін жобалауды және әр таңдаудың әсерін өлшеуді үйренесіз.

<a id="unit-u.da82cd317e354e31a90e573a50cf187f"></a>

<a id="who-this-course-is-for"></a>

## Курс кімдерге арналған

- Сервистерді басқаратын инженерлерге және сервистері не тіркейтінін білгісі келетін әзірлеушілерге.
- Doris-ті журналдар, метрикалар және трассаларға қолданғысы келетін деректер инженерлеріне.

Қажет білім:

- SQL: `WHERE`, `GROUP BY` және біріктірулері бар `SELECT`. Курс Doris-тің өз синтаксисін түсіндіреді.
- Docker: контейнер іске қосу, журналын оқу және Docker жадын баптау.
- Python мен Jupyter: ноутбук ұяшықтарын орындау және шағын Python кодын оқу.
- Doris, OpenTelemetry не Grafana туралы алдын ала білім қажет емес.

<a id="unit-u.15f15be645514e9b889d9d1d4a4db968"></a>

<a id="what-you-will-learn"></a>

## Не үйренесіз

- OpenTelemetry Collector конвейерлерімен журнал, метрика және трассаларды Doris-ке жинап, жеткенін SQL-мен тексеру.
- Grafana-да инцидент тексеру: Lucene және SQL арқылы журнал іздеу, трассамен ақау басталған span-ға жету, бақылау тақтасын құру.
- Doris телеметрия кестелерін жобалау: модельдер, бөлімдер мен bucket-тер, compaction мен сығу, кері индекстер және материалданған көріністер; әсерін `EXPLAIN` және Query Profile арқылы өлшеу.
- SQL-мен трасса талдау: ақау үлестері, процентильдер, ақау бастауы және терезелік функциялар; дерегін Doris-те сақтайтын Litefuse арқылы LLM қолданбасын трассалау.
- Doris сұраулары бойынша Grafana ескертулерін жасау, хабарландыруларды бағыттау және ережелерді кодпен сақтау.

Курс Apple silicon және Docker Desktop бар macOS-та тексерілген; Apple silicon ішінде орта ұяшығы демо Java сервистеріне M4 және кейінгі чиптерде қажет Java параметрін қосады. - **Жүктеулер:** DOG стегінің бейнелеріне шамамен 2.1 GB, демоға 2.7 GB. 7-модуль Litefuse үшін 1.2 GB, оның қосымша 7A жұмысы модель серверіне 300 MB және модельге 491 MB жүктейді. Grafana алғаш қосылғанда екі шағын плагинді, 8-модуль 2 MB `busybox` бейнесін жүктейді.

### Linux жүйесінде

Курс тек macOS Docker Desktop ішінде тексерілген. Linux Docker Engine үшін мына қадамдар өзгеше:

- Docker Engine мен Compose плагинін [Docker репозиторийінен](https://docs.docker.com/engine/install/) орнатыңыз. Дистрибутив пакеті Compose 2.24.4-тен ескі болуы мүмкін; орта ұяшығы соны хабарлайды.
- Ноутбуктер `docker` орындайтындықтан, пайдаланушыңызға `sudo` қолданбай рұқсат беріңіз: `sudo usermod -aG docker "$USER"`, кейін жүйеден шығып қайта кіріңіз.
- Docker Engine-де жады баптауы жоқ: контейнерлер компьютер жадын Jupyter және браузермен бөліседі. Оларға кемінде 10 GB бос ұстаңыз.
- Debian мен Ubuntu ішінде `python3 -m venv` үшін `python3-venv` пакеті керек, мысалы `sudo apt install python3-venv`.
- Doris `.runtime/doris-logs/` ішіне root ретінде жазады, сондықтан компьютерде де файлдар root-қа тиесілі. `lab.teardown()` соңында оларды пайдаланушыңызға береді; `.runtime/` жоймас бұрын соны орындаңыз.
- Rootless Docker және Podman сыналмаған. Мысалы демо collector-ы Docker сокетін `/var/run/docker.sock` жолына байланыстырады.

<a id="get-started"></a>

## Бастау

1. Docker орнатып, кемінде 10 GB жады беріп, іске қосыңыз. Linux-та алдымен [Linux жүйесінде](#on-linux) бөлімін оқыңыз.
2. Курстың Python ортасын құрыңыз. Осы каталогта Python 3.10–3.13 арқылы орындаңыз:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   python -m pip install -r requirements.txt
   ```

   `requirements.txt` курстарға ортақ ноутбук ортасы `doris_labkit` пакетін `../../common` ішінен де орнатады. Сондықтан команданы осы каталогтан орындап, репозиторийді тұтас сақтаңыз.
3. Сол каталогтан `.venv/bin/jupyter lab` арқылы JupyterLab бастаңыз.
4. [1-модуль](level1/module01-observability-introduction/course.md) сабағын, кейін зертханалық жұмысын ашып, ұяшықтарды ретімен орындаңыз.

Әр ноутбуктің алғашқы код ұяшығы `lab` объектісін құрады. Әдістері ортаны іске қосады, Doris-те SQL орындайды, Grafana, Mailpit пен Litefuse оқиды; әрқайсысы жіберетін SQL не HTTP сұрауын көрсетеді, сондықтан MySQL клиентінде не `curl` арқылы қайталай аласыз. Әр жұмыс қолданар алдында қажет дерегін тексереді, ұяшықтарын қайталауға болады.

## Деректер жиыны

Курс деректер жиынын жүктемейді. Телеметрия өзі іске қосқан жүйелерден келеді:

- [OpenTelemetry демосы](https://opentelemetry.io/docs/demo/) (Astronomy Shop, Apache License 2.0): әртүрлі тілдегі шамамен он екі сервис және дүкенді қарап, минутына бір-төрт тапсырыс беретін жүктеме генераторы. Қосулы кезде Doris минутына шамамен 10,000 span, 3,000 журнал жолын және сервистер, хосттары мен контейнерлері метрикаларын алады.
- Инцидент: 1-модульде 50% орнататын `paymentFailure` жалаушасы payment-ті төлемдердің шамамен жартысын қабылдамайтын етеді; тапсырыстардың жартысына жуығы сәтсіз болады.
- 2-модуль collector-лары жүктейтін Doris FE-нің өз журналы мен метрикалары.
- 7-модуль Litefuse-ке жіберетін имитациялық моделі бар шағын LLM қолданбасының трассалары.

Doris телеметрияны `otel` дерекқорында, Doris экспорттаушысы құратын кестелерде, UTC уақытымен, әр UTC күніне бір бөлімде, 7 күн сақтайды. Litefuse кестелері сол Doris-тің `litefuse` дерекқорында.

<a id="clean-up"></a>

## Тазалау

- `lab.stop_demo()` демо контейнерлерін және Docker оларға құрған томдарды тоқтатып жояды. Doris-тегі телеметрия қалады, `lab.start_demo()` демоны қайта іске қосады. Мүмкіндік жалаушалары демо бетінде орнатқан күйде сақталады; 8-модуль `paymentFailure` мәнін `off` етеді.
- `lab.stop_litefuse()` Litefuse контейнерлерін тоқтатып жояды. Пайдаланушысы, кілттері, трассалары томдары мен Doris-те қалады; `lab.start_litefuse()` солармен қайта қосады.
- `lab.stop_local_model()` қосымша 7A модель серверін тоқтатады. Жүктелген модель томында қалады.
- `lab.teardown()` курстың барлық контейнері, желісі мен томын жояды: демо, Litefuse, жергілікті модель, 2-модуль collector-лары, әлі қосулы болса 8-модуль CPU жүктемесі, DOG стегі және 3-модуль тақтасы мен 8-модуль ескертулері бар Grafana томы. 2-модуль журнал collector-ының оқу орны сақталатын `.runtime/collector-state/` каталогын да жойып, демо жалаушаларын өшіреді. `lab.teardown(keep_data=True)` DOG стегінің, Litefuse пен жергілікті модельдің томдарын, оқу орнын және жалаушаларды сақтайды; кейін `lab.prepare_environment()` және `lab.start_litefuse()` сол деректермен жалғасады.
- Upstream көшірмесі мен Doris FE журналдары `.runtime/` ішінде қалады. Қажет болмағанда каталогты жойыңыз. Doris журналдарын root ретінде жазады; `lab.teardown()` оларды сіздің пайдаланушыңызға береді, сондықтан Linux-та да жоя аласыз.

## Ақауларды жою

- **Порт қолданыста.** Орта ұяшығы еш контейнер бастамай тұрып тоқтап, порт айнымалысын атайды. Оны қолданған бағдарламаны тоқтатыңыз не айнымалыға бос порт орнатып, Jupyter-ді қайта іске қосыңыз.
- **Демо басталмайды не контейнерлері қайта-қайта іске қосылады.** Docker жады аз болуы мүмкін: кемінде 10 GB беріңіз не Linux-та сонша босатыңыз. Ұяшық жұмыс істемейтін контейнерлерді тізеді; `docker logs <container>` себебін көрсетеді.
- **Docker «permission denied» хабарлайды (Linux).** Пайдаланушыңызда Docker рұқсаты болмауы мүмкін. `sudo usermod -aG docker "$USER"` орындап, жүйеден шығып қайта кіріңіз, Jupyter-ді қайта қосыңыз.
- **`.runtime/` жойылмайды (Linux).** Doris файлдарды root ретінде жазған. `lab.teardown()` не деректі сақтау үшін `lab.teardown(keep_data=True)` орындаңыз; ол файлдарды пайдаланушыңызға береді, кейін каталогты жойыңыз.
- **Discover не Traces нәтиже көрсетпейді.** Doris App 1.0.5 компьютердің уақыт белдеуіндегі аралықты Doris UTC уақытымен салыстырады. Сондықтан компьютер UTC болмаса, Last 15 minutes сияқты салыстырмалы аралық жаңа жолдарды өткізіп алады. Абсолют UTC аралығын орнатыңыз; 3-зертханалық жұмыс шығарып береді. Grafana тақталарына әсер етпейді.
- **Тапсырыстар сәтсіз болмайды.** [http://127.0.0.1:28082/feature](http://127.0.0.1:28082/feature) жалауша бетінде `paymentFailure` — `50%` және демо қосулы екенін тексеріңіз. Жүктеме генераторы минутына бір-төрт тапсырыс қана береді, алғашқы ақауға бірнеше минут кетуі мүмкін.
- **8-модульде Grafana әкімші құпиясөзін қабылдамайды.** Алғаш кіргенде жаңа құпиясөз орнатсаңыз, жұмыста `GRAFANA_ADMIN_PASSWORD` мәнін соған орнатыңыз. Басқа ұяшықтар Grafana-ны жүйеге кірмей оқиды.
- **Қосымша 7A моделі жүктелмейді.** huggingface.co қолжетімсіз болса, Jupyter бастамас бұрын `DORIS_OBS_LLM_MODEL_URL` мәнін айнадағы сол модель файлына орнатыңыз.
