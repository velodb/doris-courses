# Website multilingual consumer

New source releases use the independent course-file v3 package and
`--interface v3`. The website validates committed language files and generated
projections without source maps, translated unit overlays or English paragraph
alignment. The compiled website format and existing grade/route identities stay
compatible. The following v2 details describe supported historical releases.


The VeloDB website consumes this contract through a separate, pinned admission
and compiler. Its operational entry is `docs/courses-multilingual.md` in the
website repository. The consumer supports the RTA Module 1 English/Kazakh pilot
and complete RTA, Data Warehousing and Observability profiles behind a deployment
switch. The complete selections contain 32 primary modules and all nine optional
or extension materials. Local qualification does not enable a production
language or complete production release qualification.

The website independently selects the full course Git SHA and private package
digest, fetches that source, then validates the package with website-owned
schema, registry and validator copies. It never imports package Python/JS or
runs package installers. Its compiler checks actual assets and selected profile
coverage before creating a complete website snapshot.

The original English adapter and routes remain available. A partial translated
profile does not reduce the English course's required modules, reset passed
credit or create another certificate identity. Kazakh routes use
`/courses/l/kk-Cyrl/…`; aliases canonicalize to that tag. Only admitted modules
appear in localized discovery, hreflang and sitemap entries. Unselected links
identify English content or an unavailable response.

| Website data | Delivery |
| --- | --- |
| Localized lesson, guide and Lab preview | Sanitized website rendering with stable unit anchors and original heading aliases. |
| Original English diagrams | Original pixels with the adjacent translated alt, caption and label legend. |
| Selected Lab and shared code/data downloads | Exact generated bytes behind an immutable, hash-bound download allowlist; attachment MIME and `nosniff`. |
| Selected optional lessons, extension Labs and optional Quiz Notebook | Locale-specific optional routes; exact Notebook downloads and answer-free self-study questions. Optional work never grants primary module credit. |
| Displayed Quiz | Answer-free question/option text, stable IDs, opaque semantic/public-release handles and presentation revision. |
| Grader, authoring Quiz YAML and binding inventories | Private server files, excluded from public assets and downloads. |
| Attempt feedback | Owner/activity-authorized submission receipt or result view. |

Quiz presentation rows bind the new semantic/presentation revisions to the
existing English quiz release. Website migrations are additive. Historical
digests, numeric revisions, attempts, passed flags, completions and certificate
fields retain their original values; unknown legacy display metadata remains
null. Reusing a semantic revision with another grading payload is rejected.

An equivalent in-widget language switch keeps the current question, ordered
options and unsubmitted selections. Submission freezes the locale, release,
answers and idempotency key. A lost response retries that same request; changed
submissions conflict. Result-language GETs check ownership and semantic/release
equivalence without creating attempts or changing the original receipt. Stale
clients must reload when their original binding is unavailable.

Website identity and credit come from its existing trusted session/CSRF and
database boundary. A local preference is scoped by a server-derived
learner/activity hash. It cannot choose identity or grant credit. Portable
Workshop records remain self-study data; the website has no credential import
endpoint for them.

Candidate packaging verifies compiled file hashes and complete release
bindings. The existing candidate process workflow checks health and real
legacy/multilingual HTTP routes before activation. Rollback selects an earlier
complete website/content pair and retains additive database history. An old
binary requires a compatible v1 snapshot.

Website UI translations have their own attributed current-session LLM checks.
They do not change this producer's units or checked course overlays. Native
human language review, other browsers/operating systems, production release
qualification and cloud publication remain separate checks.
