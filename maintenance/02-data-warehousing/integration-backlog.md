# Level 1 尚未交付的实验

这些内容属于已规划的 Level 1，不因首版未实现而从课程目标中删除。
没有通过实验的路径不得进入录制稿的“成功结果”。

## 讲义与实验的边界

七份学员讲义现已补齐概念、示例和结果解释。作者的录制、环境固定和实验开发
待办集中放在本文件，不再穿插到正文作为“观察与练习”。学员材料仍明确说明
需要哪些环境、哪些步骤不可执行，以及小样本和模拟事件不能证明什么。
本表的实验尚缺项没有因讲义完善而变为已完成。

离线测试通过或单节点开发构建成功等同于全部课程验收。
